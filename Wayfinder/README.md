# Wayfinder 1.0.0

Character-aware quest routing for WoW: Forever. Keep QuestieDB (Forever) enabled; Questie is strongly recommended.

See the [full installation, controls and scope documentation](https://github.com/CodeByNiko/wayfinder-wow-forever#readme).

Use `/wf` to show the guide, `/wf arrow` for the movable navigator and `/wf debug` for local diagnostics. The **…** button opens character preferences. Accept and turn in quests normally; Wayfinder advances from live quest changes.

The arrow gives target direction. Use roads, bridges and cave entrances. Missing or inaccurate Forever database targets can be deferred using **Skip 15 min**.
