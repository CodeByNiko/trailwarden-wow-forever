Wayfinder 1.0.0 resumes quest routing from the character you are playing, with a redesigned guide and independent movable navigator.

- Character-specific progression and preferences; no shaman route imposed on alts.
- Dynamic accept, objective, delivery and turn-in steps with chain availability.
- Solo comfort settings, nearby quest batching, full-log awareness and route stability.
- NPC/object/item-source routing and live NPC offer observations.
- Clear next action, four planned steps, focus/skip controls and saved layouts.
- Custom navigator with its own distance and explicit arrival/transit states.
- Automated scenario checks and a directly installable package.

Download **Wayfinder-1.0.0-Forever.zip** below. Exit WoW, replace the `Wayfinder` folder under `Interface/AddOns`, then restart. Keep QuestieDB for Forever enabled; Questie is strongly recommended.

This version was checked with deterministic client doubles and package validation. Actual Forever gameplay still needs live confirmation. QuestieDB may lack some new Forever content, cave/phase targets or scripted objectives. The arrow gives direction rather than a terrain-safe path. Use `/wf debug` for local diagnostics if a step does not match the game.
