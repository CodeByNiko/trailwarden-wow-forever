# 1.7.1: local work, opportunities and escort continuity

## Underlying failure

The reported Ban'ethil screenshot has unfinished Relics of Wakening collection while the selected Crown of the Earth objective requires leaving. Version 1.7's nearby-work boundary only applied to pickup, delivery and turn-in candidates, not competing quest objectives. Its regional commitment treated the whole zone as one area. Cave detection happened later in navigation, so the UI correctly recognized the cave while explaining the wrong selected goal. Pure XP rankings could consequently choose a different objective in the same zone.

Related discovery gaps included looking up pickup catalogs with a cave-floor map ID instead of its parent zone, choosing a nearest projected source outside a cave, and ranking an eligible nearby offer below a modeled outside quest. These are code-level findings consistent with the report. Without the user's installed-provider diagnostics, the exact availability gate for the originally missed offer is not proven.

## General policy

1. Keep confirmed unfinished local work ahead of moving to a distant objective, town or another area. Treat this as an ordering boundary, not an XP score discount. Evaluate the same rule between queued legs.
2. Feed observed location context into selection, not just the arrow. Recognized cave records provide stronger area membership; live indoor/subzone context and bounded map-parent traversal also support unnamed interiors/floors.
3. Observe actual quest-count changes independently of XP measurement. Maintain a temporary local quest focus while that work remains unfinished and local. Completion, failure, character/context change or walking away releases it; explicit skips/focus remain available.
4. Choose inside-area acquisition sources only among already eligible source points. Never relax combat-level restrictions to retain a batch. If recent local work has no safe mapped next step, show a review step rather than silently leave.
5. Keep nearby eligible pickup opportunities visible. Do not start an exit escort before finishing current local collection. Consider the nearby escort before departing once the local work is done.
6. For an already accepted escort with recognizable provider event metadata, follow the escort NPC until completion/failure. Do not navigate independently toward the final event coordinate. Safety stops and explicit overrides remain effective.

No runtime quest-ID exceptions implement these policies. The real Forever quest 99053 is used only in a test fixture. The engine remains pure: observed context, progress focus and candidate activity metadata are captured in plain replay inputs; game/provider reads stay outside selection.
