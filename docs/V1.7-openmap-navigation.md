# 1.7 development: navigation owned by Wayfinder, displayed with OpenMap

Status: **unreleased foundation; not yet a terrain-routing implementation**. The stable release stays at 1.6.0. No additional navigation addon or external service is introduced.

## The reported failure

The Night Elf Warrior is outside Fel Rock at approximately 53.4,54.9. The selected Twisted Hatred objective is Lord Melenas, NPC 2038, inside the cave. The previous arrow pointed toward the objective's projected map coordinates. That direction can intersect the hillside; neither proximity nor a quest spawn coordinate establishes a walkable connection.

There are two separate responsibilities:

1. The existing quest planner chooses useful work, observes completion and applies combat limits.
2. A walking planner needs known traversable connections, cave entrances, floors and exits. Its next navigation point can differ from the final quest target.

OpenMap supplies map display and integration APIs. Its cave bounds describe map artwork placement. They are **not collision geometry, a navigation mesh, or a graph of walkable tunnels**. Its current Routes.lua draws boat/zeppelin routes, not pedestrian paths. Drawing a line between arbitrary spawn coordinates would repeat the original failure.

## Implemented on this branch

- Separate final quest target from access/navigation target, leaving quest progress untouched.
- Recognize Fel Rock, Shadowthread Cave and Ban'ethil Barrow Den using current Forever cave map IDs/bounds; additionally recognize Lord Melenas by NPC ID.
- Prefer a matching live Forever cave POI when supplied by the client. Guard against reused POI IDs by matching the linked cave map or localized cave name.
- Otherwise show a clearly labeled reference entrance. Historical AreaPOI coordinates still need live Forever confirmation. A reference entrance is not a validated approach corridor.
- Navigate toward the entrance before the underground objective. Proximity alone never advances to an interior stage. Actual cave-map identity, or matching indoor subzone evidence, changes the access stage.
- Inside a recognized cave, suppress the direct bearing when the tunnel route is unknown. The cave map and objective marker remain useful, but no tunnel path is invented.
- Cyan entrance and gold objective markers on the minimap and world map via Questie's HereBeDragons pins; OpenMap displays these world-map pins through its supported integration. `/wf routepins` and OpenMap's Wayfinder access-points toggle control them.
- Preserve independent panel/arrow scales, map ownership and combat-safety behavior. No forced OpenMap settings or external navigation settings.

**There is deliberately no walking polyline yet. This branch does not fulfill the complete requested 1.7 feature and must not be released as if it did.**

## Required before the 1.7 release

1. **Establish the traversal dataset.** Start with the two active regions, Teldrassil and Duskwood. Record the provenance/build and validate each road, entrance approach, bridge and tunnel connection against Forever. Map artwork alone is insufficient. No usable pedestrian network was found in OpenMap's published data/API during this review.
2. **Implement Wayfinder's own walking graph.** Keep surface corridors, cave/floor transitions and one-way links explicit. Find a path over validated edges, never attach a target or player to a nearby node merely because its 2D coordinates are close across a wall. Unknown approach/exit legs must stay visibly unknown.
3. **Draw only supported route sections.** Render the same ordered path on the minimap and OpenMap, with clipping/rotation/zoom handled by the existing map library. Distinguish any incomplete leg; never present a direct segment through unknown terrain as a confirmed route.
4. **Advance navigation without completing quests.** Follow the next path point, with a small arrival radius, stable route commitment and bounded deviation checks. Replan on meaningful route departure, access/floor transitions or final-goal changes, not after every mob kill.
5. **Validate actual walks.** Reproduce Dolanaar → Fel Rock entrance → Lord Melenas → exit, relevant Ban'ethil floors, and Duskwood roads/objective batches. Include a player above/beside a cave, missing position, map rotation/zoom, death, danger and unavailable path sections.

The traversal dataset is the outstanding prerequisite for a reliable walking route. No complete terrain graph, first-visit path coverage or in-game navigation success is claimed by this development branch.
